# Contributing to Awesome REA

Thanks for helping keep this list useful.

## What belongs here

- Resources about [REA](https://github.com/morluto/rea) itself: docs, guides, case studies, integrations, articles, talks, videos, and community projects.
- Critical and negative reviews are welcome. The list should help people decide, not sell.
- Related tools only if REA drives them or they are a direct complement.

## What does not belong

- Anything that helps bypass licensing, DRM, or access controls on software you are not authorized to analyze.
- Content farms, affiliate pages, or articles that only restate the README.
- Star-count trackers and hype posts without technical content.

## Adding an entry

1. Search the list first to avoid duplicates.
2. Put the entry in the most specific section. Add a section only if three or more entries would fit it.
3. Use this format: `- [Title](https://link) - One sentence, ending with a period.`
4. Keep the title as the page calls itself. Add the language in the description for non-English resources.
5. Link to the canonical URL, not a mirror, shortener, or tracking link.
6. Open a pull request with one entry per commit and a short reason in the description.

## Removing an entry

Open an issue or PR if a link is dead, moved, or no longer accurate. Dead links are checked automatically by the link-check workflow.
